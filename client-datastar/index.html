What this stack does not do

No lanes here

No WebTransport, no WebSocket, no datagrams, no upload lane: a hypermedia client holds no transport in the browser to exercise. That is not a missing feature — it is the trade. Everything interactive on this page is a plain HTTP request, and everything live is the server patching HTML over one SSE stream. Compare the ledger panels in client/ and client-lit/ to see what owning the transport buys, and this page to see what letting the server own it costs: almost nothing to build, and no say in how the bytes travel.
